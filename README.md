# 神社知識マップ｜スマホ・タブレット操作改善版

## 公開サイトへの適用

既存のGitHubリポジトリ `ko-max-123/shrine-knowledge-map` を想定した**差し替えパッチ**です。
ZIP内の `index.html` と `js/app.js` **だけ**をリポジトリ内の同名ファイルへ上書きしてください。

**`data/` 以下のYAMLは変更しません。** 建築様式・社格・神紋など、すでに公開済みのデータをそのまま読み込みます。GitHub Pages の設定変更も不要です。

1. GitHubのリポジトリで `index.html` を置換してCommit。
2. `js/app.js` を置換してCommit（ファイルは `js/` の中）。
3. Actions/Pages のデプロイ完了後、スマホでページを再読み込み。
4. 更新が見えない場合はブラウザのサイトデータ／キャッシュを確認。

既存ファイルに独自修正を入れている場合、差し替え前にその変更を保存してください。`data/` は触らないでください。

## 改善点

- スマートフォン・タブレットの**1回タップは即時に詳細を開く**。2回タップは円を中心へ移動。
- 詳細を出した直後のカメラ移動を約0.4秒保留し、2回タップの2度目が外れないよう調整。
- 円の上からでもスワイプでマップをドラッグ可能。
- **2本指のピンチ拡大／縮小**と2本指での移動に対応。
- 詳細内は縦スクロールを継続。
- 関係線のSVG要素を毎フレーム再生成せず、既存要素の座標だけを更新。
- 公転計算に使うグラフ構造をキャッシュ。位置更新にCSSの `translate` を使用。
- 公転の画面更新頻度を目安としてPC最大30回/秒、タッチ端末最大18回/秒に制限。
- 詳細表示中・ドラッグ中・ページ非表示中は、アニメーション処理を休止。
- タッチ端末では背景の多重パターンや影を簡略化し、描画負荷を低減。
- 既存のYAMLファイル構成、データの読み込み、外観、マップ上の詳細カードは維持。

## 操作

| 操作 | スマートフォン・タブレット | PC |
| --- | --- | --- |
| 詳細 | 1回タップ | クリック |
| 中央へ移動 | 素早く2回タップ | ダブルクリック |
| マップ移動 | 1本指でスワイプ（円の上も可） | ドラッグ |
| 拡大・縮小 | 2本指でピンチ | マウスホイール |
| 詳細を閉じる | マップの空白をタップ | 空白をクリックまたはEsc |

## 動作確認

Chromiumでモバイル（390×844）、タブレット（820×1180）、PC（1440×900）の画面をエミュレーションし、初期表示、枝の中心切り替え、詳細表示、関係線のDOM再生成なし、タッチのダブルタップ、2本指ズーム、詳細とノードの重なりを検査しました。**実機SafariやAndroid Chromeでの体感速度は未測定**です。

## 注意

- GitHub Pages上では `data/manifest.yaml` などをHTTPSで取得します。`file://` での直開きは従来どおり対象外です。
- YAML解析には従来と同じ外部の `js-yaml` が必要です。
- 端末性能、通信速度、表示ノード数により体感速度は変わります。
